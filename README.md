# Full Stack Open

This repository contains my solutions to the exercises from the **Full Stack Open** course by the University of Helsinki.

The course covers modern full-stack web development using JavaScript and TypeScript, with a strong focus on building production-quality applications. Topics include React, Node.js, Express, MongoDB, REST APIs, testing, authentication, state management, GraphQL, CI/CD, containers, and more.
